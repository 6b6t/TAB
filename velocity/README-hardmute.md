# Hard-mute visibility

Velocity TAB reads hard-mute UUIDs from AsyncChat's authoritative `asyncchat_uuid_mutes` table (`hard_mute = TRUE`). Hard mutes do not expire; temporary mute timestamps are stored in epoch seconds and are not used for this query. The connection is read-only and polls every two seconds. A status change reconciles existing tab entries on TAB's CPU thread, even when `global-playerlist` is disabled, and outbound player-info updates are filtered as they pass through TAB, including entries arriving from another proxy. A muted player keeps their own entry. Legacy clients retain the PlayerInfo entry they need to render the player's in-world entity; TAB concealment applies to modern clients that support unlisted entries.

The reader uses the same environment variable names as AsyncChat: `CONFIG_ASYNCCHAT_DATABASE_HOST`, `CONFIG_ASYNCCHAT_DATABASE_PORT`, `CONFIG_ASYNCCHAT_DATABASE_DATABASE`, `CONFIG_ASYNCCHAT_DATABASE_USERNAME`, and `CONFIG_ASYNCCHAT_DATABASE_PASSWORD`. When those are not set, it reads the same settings from `plugins/tab/hardmute-db.properties` (keys `host`, `port`, `database`, `username`, `password`; keep the file readable by the proxy user only), so the login can be added without changing the proxy deployment. Deployment prerequisite: provide both proxies with a dedicated read-only database account that has `SELECT` only on `asyncchat_uuid_mutes`, and allow proxy-to-database network access. Do not reuse AsyncChat's read-write account. If any required setting is missing or the query fails, TAB logs one warning for that unavailable period and fails open. Deploy the PlayerNotifications jar to all workers together because older workers ignore the hard-mute flag in notification messages during a mixed-version rollout.

The connection announcements in `6b6t-plugins/proxy/JoinNotifications` and `VelocityWelcomeMessage` are delivered only to the joining player. No proxy plugin in that repository broadcasts public join, leave, or server-switch lines; those lines are emitted by backend server software and are outside this Velocity TAB change.
